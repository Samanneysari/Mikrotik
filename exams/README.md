# Original Practice Exams

These are original learning questions, not copied certification items. Use 60 minutes for each 25-question set, matching the public MikroTik certification FAQ format. Score one point only when every selected option is correct; target at least 80% here even though the official public pass score is 60%.

- [MTCNA practice exam](mtcna-practice-01.md)
- [MTCRE practice exam](mtcre-practice-01.md)
- [MTCINE practice exam](mtcine-practice-01.md)

Method:

1. answer closed-book and mark confidence 1–3;
2. score only after all 25;
3. for every wrong or low-confidence answer, build the smallest lab that proves it;
4. explain why each distractor is wrong;
5. retake after at least 48 hours with option order hidden/shuffled manually.

Reading answers is not practice. Prediction, configuration, and evidence are practice.
