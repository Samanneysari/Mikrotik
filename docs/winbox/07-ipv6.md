# IPv6 Menu

IPv6 is a separate protocol family. IPv4 addresses, ARP, DHCP and firewall
rules do not configure or protect IPv6. Link-local addresses and ICMPv6 are
fundamental, not optional noise.

## IPv6 → Addresses

Lists address/prefix, interface, actual interface, EUI-64/advertise/no-DAD and
dynamic/global/link-local state. Click **+** to set Address/prefix, Interface,
EUI-64, Advertise, No DAD and comment. `/64` is normal for SLAAC LANs; do not
invent shorter host-style LAN prefixes casually. A Router Advertisement policy
is separate under ND.

## IPv6 → Neighbors

IPv6 Neighbor Discovery cache: IPv6 address, MAC, interface, status, router
flag and dynamic state. States such as reachable, stale, delay, probe, failed or
incomplete describe Neighbor Unreachability Detection. A failed row leads first
to link/VLAN/prefix/ND diagnosis. Static neighbors are created only for an
explicit design.

## IPv6 → Routes

Displays connected, static and dynamic IPv6 routes with destination, gateway,
immediate gateway, table, distance, scope and protocol flags. Add a static route
with prefix (default is `::/0`), IPv6 next hop—often link-local qualified by
interface—distance/table and type. A link-local gateway without interface scope
is ambiguous.

## IPv6 → ND

**Purpose:** send Router Advertisements and control host Neighbor Discovery.

The interface row includes Interface, RA interval/lifetime, reachable/retransmit
timers, managed/other-configuration flags, DNS advertisement, MTU, hop limit and
preference. **Prefixes** define prefix, autonomous/on-link flags, valid/preferred
lifetime. **RDNSS/DNSSL** advertise resolver/domain information where supported.

Enabling Advertise on an address is not enough if ND is disabled or firewall
blocks required ICMPv6. Do not set Managed unless stateful DHCPv6 design exists.

## IPv6 → DHCP Client

Requests delegated prefixes and/or options from upstream. Fields include
Interface, Pool Name, Pool Prefix Length, request type (`prefix`, `address`,
`info`), add default route, rapid commit and script. Status shows bound prefix,
server DUID and lifetime. A delegated prefix pool still needs assignment to LAN
addresses/ND.

## IPv6 → DHCP Server

Server instances bind interface, address/prefix pool, lease time, preference,
rapid commit and RADIUS. **Bindings** show client DUID/IAID, address/prefix and
status. **Options/Option Sets** carry encoded information. DHCPv6 does not
deliver an IPv4-style default gateway; hosts learn routers through RA.

## IPv6 → DHCP Relay

Relays client DHCPv6 messages to a remote server. Set client-facing Interface,
server address, local/source address and interface ID. Permit UDP 546/547 and
ensure link-local/return routing is correct.

## IPv6 → Pool

Creates prefix pools, commonly from DHCPv6-PD. Fields include Name, Prefix,
Prefix Length and next-pool chaining. The pool allocates subprefixes; it does not
advertise them until an address/ND or service consumes them.

## IPv6 → Firewall

Contains **Filter Rules**, **Mangle**, **Raw**, **Address Lists** and
**Connections**, using the same ordered form model as IPv4 but IPv6 match
fields. Build explicit input/forward policy and preserve required ICMPv6 types
for ND, Router Solicitation/Advertisement, errors and Path MTU Discovery. NAT is
normally absent because address conservation is not the IPv6 model.

## IPv6 → Settings

Global forwarding, accept redirects, accept/send router advertisements, maximum
neighbor entries and multipath/hash behavior as available. A host/router role
change here affects the whole device; record current state and use console/Safe
Mode.

## IPv6 → ND Prefix/Address Lists and legacy 6to4

Version/package-specific child views may expose ND prefixes, DNS, DHCP options,
firewall lists and 6to4 tunnel interfaces. Use the same object workflow and
confirm current CLI properties. Always perform IPv6 positive and negative tests
from every zone; “we do not use IPv6” is not evidence that it is disabled.
